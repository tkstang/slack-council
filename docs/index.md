# Slack Council

Use these docs to run a council in your Slack workspace or contribute to
the app. Set up a Slack app and choose a roster first. Use the maintainer
pages to understand the design and verify changes.

## Contents

### Use it

- [Getting started](getting-started.md) to set up the Slack app and convene your first council.
- [Configuration](configuration.md) for the JSON settings and their defaults.
- [Member tools](member-tools.md) for grants, MCP servers, approvals and handoffs.
- [Using the council](using-the-council.md) for presets, mentions and commands in Slack.
- [Deployment](deployment.md) to run the app as a long-lived service.

### Maintain it

- [Design](design.md) for the turn engine, adapters and persistence.
- [Live checks](live-checks.md) for the Slack checklist and run log.
- [Toolchain](toolchain.md) to build, test and verify a change.
- [Contributing](contributing.md) for documentation authoring conventions.
