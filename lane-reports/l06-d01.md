## Decisions

- `parseHumanAddress` reads the first eligible `preset:<name>` or `preset=<name>` token after applying its existing Slack markup filter. The token starts the message or follows whitespace. The key is case-insensitive, and the name is a nonempty sequence through the next whitespace or end of text. Name matching preserves case and punctuation. Masked links, quotes, and code cannot supply a token.
- The unknown-preset notice reads “Unknown preset. Available presets: \`default\`, \`Review\`.” The names come from config and appear as inline code.
- The service catches `E_UNKNOWN_PRESET`, persists the handled-message key in the existing state queue, then posts the notice outside that queue.
