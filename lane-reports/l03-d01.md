## Decisions

- The loader reads the UTF-8 Markdown once per config load. Missing, unreadable, blank, and oversized files return `E_CONFIG_READ`. The limit is 8,000 UTF-16 code units.
- Loaded file text lives in `LoadedConfig.instructionsText` and passes through the service to the prompt builder. Saved council settings exclude both the path and the text. Restored councils use guidance from the current startup config, with no state migration.
- Each marked server contributes at most 8,000 UTF-16 code units, including the visible `[Orientation truncated]` marker. A marked server with absent or blank instructions logs one `mcp_orientation_missing` warning containing the server key. Orientation blocks follow config key order and use the same grant predicate as tool exposure.
- The system message contains the role brief below. The user message repeats that brief inside `<council_role>` and then includes the transcript. The guidance sentence appears when either guidance block is present.
