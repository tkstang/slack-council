## Learnings

- Public generation omits `maxOutputTokens`, so the provider sets its own output limit. A provider `length` finish returns `E_TURN_FAILED`. The app's 600-token cap applies to private listening only.
- Slack posts still truncate at 12,000 UTF-16 code units. Typical 1,000-word prose fits, while long URLs or code can exceed the limit. An unusually large panel can also lose trailing lines at that bound. Changing either behavior would require changing the single-message posting contract or the provider configuration.
